# huiben-studio v0.0.7（2026-09-24）

## 新功能
- 开放用户语音生成：可自选音色生成配音，音色支持按标签筛选
- 绘本编辑器的旁白接入语音生成，生成的音频会自动归档到作品素材
- 编辑器新增预览放映模式：可全屏分页放映，每页旁白可单独播放或静音
- 首页输入提示词可直接创建故事作品，进入故事编辑器继续生成
- 故事编辑器新增「故事角色」面板：可查看与编辑角色信息、重新分析，选中角色后按正文高亮对应称呼，代词等指代不明确的称呼不标记
- 故事编辑器新增镜头面板：选中镜头时在正文高亮对应原文，面板折叠状态按作品记住
- 故事分析支持纯景物内容：没有独立角色时也能正常完成分析
- 作品页新增「文章草稿」分类，文章与绘本分开展示，并可从该入口直接新建文章
- 创作画布：系统模板实例化为可编辑的真实图层，形状图层支持钢笔路径蒙版
- 创作画布：文字图层可设为模板文字插槽，图片元素双击即可进入裁切调整，调整时显示完整原图参考
- 形状图层支持直接在画布上编辑节点与边，绘制时按住 Shift 可按 1:1 等比锁定
- 背景图设置支持从素材库拖入或上传本地图片
- 新增「旧画卷」系列系统模板
- 系统素材库改为按分类分页加载
- 生图分辨率新增 4K 档位
- 管理台运行配置支持逐项导出 JSON 与多文件分块导入，导入前预览差异、冲突项可逐项选择，合入结果先写入草稿
- 积分包支持限购：超出限购数量无法下单，未支付订单同样占用名额，入账按下单时冻结的权益发放
- PPT 与 PDF 导出改为按图层生成，导出结果中的每个元素可单独选中编辑

## 改进
- 语音生成改为后台合成，生成期间刷新页面仍保留余额展示
- 标签页选中指示块改为跨项滑动动画
- 下拉选择控件样式统一，新增通用选项下拉组件
- 图层面板按形状类型显示对应图标
- 编辑器内容写入改为延迟合并，页面退出时同步落盘，减少频繁编辑时的卡顿
- 导出弹层展示进度条与阶段状态，导出中按钮切换为加载态
- 新建空白分镜不再预填引导文字，避免其被当作正文参与配音与导出
- 画布文字内联编辑沿用展示态排版，保留换行与原始大小写
- 生图提示词携带最新角色设定，且不把角色强加进每个镜头
- 镜头分析补充原文引用，选中镜头按原文片段定位
- 首页创作要求卡片展示更新时间，故事角色与镜头列表样式统一

## 问题修复
- 修复管理台保存场景默认路由后整表刷新、冲掉其他未保存选择的问题
- 修复新建分镜可能认领到其他页面旁白音频的问题
- 修复素材库删除确认弹窗长文案撑破弹窗宽度的问题
- 修复形状元素几何未铺满边界、元素放大后外框出现留白的问题
