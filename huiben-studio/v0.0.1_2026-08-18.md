# huiben-studio v0.0.1（2026-08-18）

## 新功能
- 上线绘本创作流程：从分镜设置到分镜画面生成的多阶段创作向导
- 新增生成编辑器，支持画布文字、图形元素、图层锁定与排序、画布尺寸与出血设置
- 画布支持缩放、平移、动态标尺、元素多选与快捷键面板
- 编辑器内置撤销重做、字幕栏与可折叠侧边面板，支持平滑过渡与悬停唤出
- 项目级素材库：按作品隔离存储，支持图片素材拖入画布成为独立图层，内置 SVG 素材一键添加
- 素材面板接入背景音乐与图形自由变换
- 创作流程草稿持久化，编辑器头部品牌菜单整合工作区导航与编辑操作
- 作品导出支持 PDF 与 PPTX，包含帧渲染、页面上传、异步队列与本地/MinIO 存储
- 新增通知抽屉组件，替换头部静态铃铛占位为功能化通知入口，支持点击查看详情与上/下一条切换
- 落地页复刻艾绘首页并完善媒体适配，首屏改为深色视频背景主题
- 首页封面轮播改用真实绘本封面并支持作品预览
- 新增绘本编辑页与本地作品库持久化
- 完善认证、素材存储与作品持久化

## 改进
- 全局启用字标 Logo 并本地化落地页二维码
- 水墨背景迁移至应用外壳全局生效，编辑器/落地页/作品库统一主题 token 与描边样式
- 全应用统一入场动效、路由切换过渡并适配减弱动态偏好
- 优化字体选择下拉字形预览与中文字体栈

## 问题修复
- 修复素材选择状态与素材加载相关问题
- 修复编辑器画布元素属性编辑与预览同步问题
- 修复字幕与生成编辑器相关审查问题
- 修复预览/替换无变化时历史状态引用稳定性问题
