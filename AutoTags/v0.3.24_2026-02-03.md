# AutoTags v0.3.24（2026-02-03）

## 变更概览

- 引入 clap 库重构 CLI 参数解析，代码更简洁易维护
- 创建统一错误类型体系，标准化错误处理
- 拆分 compute 模块为 version/format 子模块，优化代码组织
- 新增 CheckNode/PrintableNode trait，统一节点接口设计
- 集成 tracing 日志系统，支持灵活的日志级别控制

## 详情

### Added
- `cli/clap_args.rs` - 基于 clap derive 宏的 CLI 参数定义
- `types/errors.rs` - 统一错误类型 CheckError/GitError/AiError/ReleaseError
- `nodes/version/` - 版本号处理模块（parser, sort, next, find）
- `nodes/format/` - 格式化处理模块（annotation, commit_msg, diff, tokens）
- `utils/logging.rs` - tracing 日志系统初始化
- `CheckNode` trait - 检查类节点专用接口
- `PrintableNode` trait - 可打印节点的默认实现
- `AsyncPrintableNode` trait - 异步可打印节点

### Changed
- `main.rs` - 使用 clap 解析参数，保持向后兼容
- `nodes/compute/mod.rs` - 通过重导出保持向后兼容
- `nodes/check/gh_available.rs` - 使用新的 CheckError 类型
- `nodes/check/gh_authenticated.rs` - 使用新的 CheckError 类型
- `nodes/check/remote_repo_check.rs` - 新增 check() 和 check_and_print() 方法
- `nodes/traits.rs` - 扩展 trait 体系，新增文档和示例

### Technical
- 依赖更新：添加 clap 4、tracing 0.1、tracing-subscriber 0.3
- 模块重组：compute 模块拆分为更细粒度的 version/format 子模块
- 代码量：新增约 1800 行代码，优化架构设计

## 备注

- 此版本为架构重构版本，不影响现有 API
- 通过重导出机制保持向后兼容，现有代码无需修改
- 建议新代码使用新的模块路径（如 `nodes::version::parser`）
- 日志级别可通过 `RUST_LOG` 环境变量控制
