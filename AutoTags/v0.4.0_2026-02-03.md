# AutoTags v0.4.0（2026-02-03）

## 变更概览

- 新增 MCP (Model Context Protocol) 服务器支持
- 支持 AI Agent（如 Cursor）通过 MCP 协议调用 AutoTags 功能
- 修复 MCP 模式下 stdout 输出污染 JSON-RPC 协议的问题

## 详情

### Added
- 新增 MCP 服务器模块（`mcp/`）
- 支持 stdio 传输方式
- 实现 MCP 2024-11-05 协议规范
- 提供 `autotags` 工具，支持以下操作：
  - `commit` - AI 生成提交信息并推送
  - `commit_with_tag` - 提交推送并创建标签
  - `create_tag` - 创建指定标签
  - `create_release` - 创建 GitHub Release
  - `list_tags` - 列出所有标签
  - `list_releases` - 列出所有 Release
  - `pull` - 拉取并分析远程更新
  - `delete_release` - 删除 Release

### Fixed
- 修复 `list_tags` 和 `list_releases` 在 MCP 模式下输出污染 stdout 的问题
- 添加服务器初始化状态跟踪
- 改进错误处理和日志输出格式

### Technical
- 添加 `initialized` 通知处理
- 添加 `resources/list` 和 `prompts/list` 空响应支持
- 工作目录验证（检查路径存在、是目录、是 Git 仓库）

## 备注

- MCP 配置方式：在 `~/.cursor/mcp.json` 中添加：
  ```json
  {
    "mcpServers": {
      "autotags": {
        "command": "atg",
        "args": ["mcp"]
      }
    }
  }
  ```
- `list_tags` 和 `list_releases` 已完全支持 MCP 模式
- `commit` 等复杂操作在 MCP 模式下仍有部分 stdout 输出问题，后续版本将继续优化
