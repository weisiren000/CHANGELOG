# lingyuncopy v0.0.5（2026-07-31）

## 新功能
- 新增明信片与邮票成品的高分辨率认证导出
- 后台新增生成任务状态查看与白底处理后继续执行能力
- 新增展示图片响应式派生，减少首页和素材页面等待时间

## 改进
- 更新玉泉新版明信片底图、首页文字标识、左上角品牌标识和数据库标题素材
- 提升生成任务在超时、临时网络失败、重复点击和刷新重试场景下的稳定性
- 放宽高分辨率认证成品的独立上传限制，避免大尺寸明信片被错误拒绝
- 优化明信片中作品、认证编号和项目说明文字的排版对齐
- 页面展示使用派生图片，同时保留原始素材用于生成与导出

## 问题修复
- 修复重复操作可能创建多条生成任务的问题
- 修复响应中断后重试可能重复创建任务的问题
- 修复部分明信片模板中文物位置偏差
