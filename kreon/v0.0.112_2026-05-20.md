# kreon v0.0.112（2026-05-20）

## 新功能
- 输入框支持图片引用 chip 内联展示，富文本编辑体验
- 流式输出渐进展示与特殊 token 实时清洗
- 画布工具栏收起状态持久化
- LLM 模型输入图片自动压缩（超过 512KB 自动缩放）
- 图片引用元数据分离，模型上下文与前端展示解耦
- Deliberation 模式系统性加固：状态机扩展、运行时配置端点、出图回退、异常路径覆盖

## 改进
- 图片生成工具重命名 yuz→gpt，优化请求体膨胀与存储限制
- SSE 流式传输优化：no-transform 头、纯 ASGI 中间件、进程内事件信号驱动
- 进入会话时自动续连未完成的 process_run，提升 SPA 路由切换体验
- 图片网格布局对齐优化，图片容器移除多余背景色
- 聊天气泡 Markdown 渲染体验优化

## 问题修复
- 修复生图 fallback 路径 JSON 解析崩溃（502 空响应体）
- 修复 SQLAlchemy 'prepared' 状态错误导致的 InvalidRequestError
- 修复流式 deliberation 静默中断与前端假死问题（MissingGreenlet、asyncpg 连接争用、transcript 格式、SSE payload 二次序列化）
- 修复 SSE 流被 Next.js 代理 buffer 导致一次性出现的问题
