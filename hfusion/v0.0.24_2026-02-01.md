# hfusion v0.0.24（2026-02-01）

## 变更概览

- 后端架构重大重构：从 Node.js 迁移到 FastAPI Python
- 新增完整的分层架构：API、服务、仓库、模型
- 新增 Docker 容器化支持和数据库迁移工具
- 新增完整的测试框架

## 详情

### Added
- 新增完整的 FastAPI 后端架构
- 新增 API 路由层（auth, crafts, gallery, tools, users, health）
- 新增 Pydantic 数据模型和 schemas
- 新增 SQLAlchemy ORM 模型（User, Craft, GalleryWork, Tool）
- 新增仓库层（Repository Pattern）实现数据访问
- 新增服务层（Service Layer）实现业务逻辑
- 新增依赖注入系统（deps.py）
- 新增中间件（CORS、错误处理、请求日志）
- 新增核心模块（配置管理、安全、异常处理、日志）
- 新增 Docker 和 docker-compose 支持
- 新增 Alembic 数据库迁移工具
- 新增完整的测试框架（pytest）
- 新增文件上传工具
- 新增分页和验证工具

### Changed
- 更新环境变量配置示例
- 更新 README 文档

### Removed
- 移除旧的 TypeScript/Node.js 后端架构
- 移除根目录下的 package.json、tsconfig.json、eslint.config.mjs
- 移除 apps/server/src/ 目录下的所有旧代码

### Security
- 新增 JWT 认证和授权机制
- 新增密码哈希处理
- 新增基于角色的权限控制
