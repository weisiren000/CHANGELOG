# hfusion v0.0.27（2026-02-11）

## 变更概览

- 扩展用户模型，新增用户名、邮箱验证、个人简介等字段
- 实现用户偏好设置功能，支持主题和通知偏好管理
- 完善前端设置页面，实现与后端偏好的双向同步
- 优化开发启动脚本，增强错误处理和启动体验

## 详情

### Added
- 用户模型新增字段：username, email_verified, bio, last_login_at, password_changed_at, preferences
- 新增用户偏好设置 Schema：UserPreferences, NotificationPreferences
- 新增用户偏好设置 API 端点：获取/更新用户偏好
- 新增数据库迁移脚本添加 preferences JSONB 字段
- 用户 API 新增头像删除接口

### Changed
- 完善个人资料设置：头像上传/删除、用户名编辑、个人简介
- 完善外观设置：主题偏好（light/dark/system）与后端同步
- 完善通知设置：邮件、推送、评论、营销通知偏好管理
- 优化主题切换组件与认证状态管理
- 重构 start-dev.ps1：添加环境检查、端口冲突处理、优雅退出
- 优化 start-backend.ps1：改进虚拟环境检测和依赖安装流程
- 优化 start-frontend.ps1：增强错误处理和启动状态显示

### Technical
- 补充用户相关测试用例
- 更新用户资料更新和偏好设置 API 端点
- 优化前端 API 层类型定义

## 备注

- 本次更新为用户系统的重要扩展，支持更完善的个人资料管理和个性化设置
- 主题偏好现已支持持久化存储，切换设备后偏好设置会同步
- 通知设置为基础版本，后续版本将接入实际的邮件和推送服务
