# hfusion v0.0.23（2026-02-02）

## 变更概览

- 新增完整的用户设置页面功能
- 后端添加文件上传支持
- 优化认证流程和 API 客户端
- 添加 Windows 开发环境脚本

## 详情

### Added
- 新增用户设置页面组件（AccountSettings, ProfileSettings, AppearanceSettings, NotificationSettings）
- 新增 SettingsLayout 设置页面布局组件
- 新增 AuthProvider 认证上下文提供者
- 新增 API 客户端模块（client.ts）和用户 API 模块（user.ts）
- 新增文件存储服务（storage_service.py）
- 新增本地文件存储配置（上传目录、大小限制、允许的图片类型）
- 新增 Alembic 数据库迁移文件
- 新增 Windows 开发启动脚本（start-dev.bat, start-dev.ps1, start-prod.bat）
- 新增环境检查脚本（scripts/check-env.ps1）
- 新增后台/前台启动脚本（scripts/start-backend.ps1, scripts/start-frontend.ps1）
- 新增 avatar.tsx UI 组件

### Changed
- 优化 CORS 配置处理，改进 get_cors_origins_list 方法
- 更新用户服务端点（users.py）
- 优化 LoginForm 和 RegisterForm 认证表单
- 更新 MainNavbar 导航栏组件，增强用户菜单功能
- 更新 _app.tsx 集成 AuthProvider
- 优化 auth.ts 和 auth 类型定义
- 更新 next.config.ts 配置
- 更新 docker-compose.yml 配置

### Fixed
- 修复 CORS origins 配置解析问题

### Infrastructure
- 更新 requirements.txt 依赖
- 更新 package.json 配置
- 添加 pnpm-lock.yaml 更新
