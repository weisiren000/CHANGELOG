# hfusion v0.0.29（2026-02-11）

## 变更概览

- 新增手机验证码登录（OTP）支持
- 新增邮箱和手机号绑定功能
- 改进用户名生成和清理逻辑，支持中文用户名
- 添加同设备踢出安全机制
- 优化用户信息获取接口

## 详情

### Added

- 新增手机验证码登录 API (`/auth/otp/phone/send`, `/auth/otp/phone/verify`)
- 新增邮箱绑定功能 (`/auth/bind/email/send`, `/auth/bind/email/verify`)
- 新增手机号绑定功能 (`/auth/bind/phone/send`, `/auth/bind/phone/verify`)
- 新增 `sms_service.py` 短信服务
- 新增数据库迁移文件 `b8c6e2f9a113_add_user_phone_fields.py`
- 新增前端 `account-display.ts` 账户显示组件

### Changed

- 改进 `auth_service.py`，添加手机验证码登录和账号绑定逻辑
- 优化 `auth.py` 端点，新增多个 OTP 相关接口
- 改进用户名生成逻辑，支持中文用户名
- 增强 `validators.py` 手机号验证功能
- 优化 `get_me` 接口返回完整用户信息
- 改进用户注册和登录时的默认昵称生成

### Technical

- 支持手机号 + 验证码登录方式
- 邮箱/手机号绑定支持验证码验证
- 同设备登录时自动踢出旧会话
- 支持中文用户名自动清理和生成
- 改进用户名字符清理逻辑

## 备注

- 此版本引入了完整的手机验证码登录体系
- 支持用户绑定邮箱和手机号
- 增强了账户安全性和用户体验
- 改进了用户名生成策略
