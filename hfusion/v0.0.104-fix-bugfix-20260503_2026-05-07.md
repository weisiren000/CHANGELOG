# hfusion v0.0.104-fix-bugfix-20260503（2026-05-07）

## 新功能
- 新增 YuzAPI 图片生成工具，支持通过 YUZ 接口生成图片
- 图生图工具支持参考图续写、编辑和多图融合（URL、Base64、本地图片均可）
- 本地 WEBP 格式参考图自动转换为 PNG 格式后再提交
- 自动从对话上下文中的历史图片作为生图参考

## 改进
- 简化工具路由逻辑，移除强制 YUZ 路由限制，提升模型选择灵活性
- YuzImageGenerationToolCard 改为可折叠设计，展示更详细的执行信息
- 优化工具执行输出逻辑，运行中状态不提前显示结果
