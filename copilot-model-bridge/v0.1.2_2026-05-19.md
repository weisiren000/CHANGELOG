# copilot-model-bridge v0.1.2（2026-05-19）

## 新功能
- 新增更完整的 OpenAI 兼容接口接入能力
- 新增可视化配置管理入口，便于直接在 VS Code 中维护 provider 和模型
- 新增多个模型能力开关，方便按模型配置工具调用、视觉和 reasoning 支持

## 改进
- 优化请求头传递，提升下游平台识别一致性
- 改进模型元数据展示，让 Copilot 侧看到的信息更完整
- 改进扩展安装后的可用性和模型加载体验

## 问题修复
- 修复部分场景下请求标识显示异常的问题
- 修复对话请求在部分环境下无法按预期透传自定义 User-Agent 的问题
