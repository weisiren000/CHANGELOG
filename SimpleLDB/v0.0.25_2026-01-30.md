# SimpleLDB v0.0.25（2026-01-30）

## 变更概览

添加 Exa Search 搜索提供商支持，扩展网络搜索能力。同时优化搜索配置管理，支持从数据库读取 API Keys。

## 新增

### 搜索功能
- **Exa Search 支持**：新增 Exa Search API 集成，支持 neural、deep、fast 等多种搜索类型。
- **搜索提供商扩展**：web_search API 现支持 `provider=exa` 参数，与 Google CSE、Tavily 并列。
- **Exa 配置组件**：前端新增 `ExaConfigCard` 组件，支持配置 Exa API Key。

### 配置管理优化
- **数据库存储 API Keys**：搜索配置（Google/Tavily/Exa API Keys）现从数据库读取，不再依赖环境变量。
- **WeightBalanceSlider 组件**：新增权重平衡滑块组件，用于调节本地搜索与网络搜索的权重配比。
- **搜索配置选择器更新**：`SearchProviderSelector` 增加 Exa 选项支持。

## 变更

### 后端
- `server/core/search/webSearch/exa.py`：新增 Exa Search 实现模块。
- `server/core/search/webSearch/__init__.py`：导出 `exa_search` 函数。
- `server/routers/web_search.py`：支持从数据库读取搜索配置，添加 exa 提供商处理逻辑。
- `server/routers/search_config.py`：扩展配置管理支持 Exa API Key。
- `server/routers/ask_question.py`：优化搜索逻辑，支持新的配置方式。
- `server/db/database.py` & `schemas.py`：扩展数据库表结构支持 Exa 配置字段。
- `server/requirements.txt`：新增 `exa-py` 依赖。

### 前端
- `web/src/modules/ask/components/search-config/ExaConfigCard.tsx`：新增 Exa 配置卡片组件。
- `web/src/modules/ask/components/search-config/WeightBalanceSlider.tsx`：重构权重滑块组件。
- `web/src/modules/ask/components/search-config/SearchProviderSelector.tsx`：添加 Exa 选项。
- `web/src/modules/ask/components/search-config/index.ts`：导出 ExaConfigCard。
- `web/src/modules/ask/components/SearchConfig.tsx`：集成新配置组件。
- `web/src/modules/ask/components/response/WebItemsSection.tsx`：优化搜索结果展示。
- `web/src/modules/ask/hooks/useSearchConfig.ts` & `useSearchLogicConfig.ts`：更新 hooks 支持新配置。
- `web/src/modules/ask/types/index.ts`：扩展类型定义支持 Exa 配置。
