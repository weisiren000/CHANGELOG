# SimpleLDB v0.0.26（2026-01-30）

## 变更概览

添加 Brave Search 搜索提供商支持，进一步扩展网络搜索能力。用户现可在 Google CSE、Tavily、Exa 之外选择 Brave 作为搜索提供商。

## 新增

### 搜索功能
- **Brave Search 支持**：新增 Brave Search API 集成，支持网络搜索功能。
- **搜索提供商扩展**：web_search API 现支持 `provider=brave` 参数，与 Google CSE、Tavily、Exa 并列。
- **Brave 配置组件**：前端新增 `BraveConfigCard` 组件，支持配置 Brave API Key。

### 配置管理优化
- **数据库存储 Brave API Key**：Brave API Key 现可从数据库读取，与其他搜索提供商配置保持一致。
- **搜索配置选择器更新**：`SearchProviderSelector` 增加 Brave 选项支持。

## 变更

### 后端
- `server/core/search/webSearch/brave.py`：新增 Brave Search 实现模块。
- `server/core/search/webSearch/__init__.py`：导出 `brave_search` 函数。
- `server/routers/web_search.py`：添加 brave 提供商处理逻辑。
- `server/routers/search_config.py`：扩展配置管理支持 Brave API Key。
- `server/routers/ask_question.py`：优化搜索逻辑，支持 Brave 搜索配置。
- `server/db/database.py` & `schemas.py`：扩展数据库表结构支持 Brave 配置字段。

### 前端
- `web/src/modules/ask/components/search-config/BraveConfigCard.tsx`：新增 Brave 配置卡片组件。
- `web/src/modules/ask/components/search-config/SearchProviderSelector.tsx`：添加 Brave 选项。
- `web/src/modules/ask/components/search-config/index.ts`：导出 BraveConfigCard。
- `web/src/modules/ask/components/search-config/WeightBalanceSlider.tsx`：优化权重滑块组件。
- `web/src/modules/ask/components/SearchConfig.tsx`：集成 Brave 配置组件。
- `web/src/modules/ask/components/response/WebItemsSection.tsx`：优化搜索结果展示。
- `web/src/modules/ask/hooks/useSearchConfig.ts` & `useSearchLogicConfig.ts`：更新 hooks 支持 Brave 配置。
- `web/src/modules/ask/types/index.ts`：扩展类型定义支持 Brave 配置。
