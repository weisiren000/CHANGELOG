# Interactive Cultural Relic Device v1.0.0（2026-05-18）

🎉 首个正式稳定版发布。

正式版集成了展厅沉浸式交互的完整功能链路，涵盖 3D 文物展示、色彩维度探索、待机屏保、年代轮播、展厅局域网部署等核心场景。

## 核心功能

- **3D 文物展示**：基于 Three.js 的文物 3D 渲染，支持轨道控制、聚焦查看、信息面板
- **色彩维度**：文物按色相排布的颜色轴，支持明度径向偏移、颜色梯度图例、材质光照简化
- **年代沿革**：年代轮播模式，支持吸附停靠、环形间距动态配置、卡片缩放
- **待机屏保**：色彩维度待机界面，聚光小球文物轨道漫游、反色蒙版、圆外文物滤镜、摄像头取色匹配
- **竖屏/窄屏适配**：InfoPanel 滚动、窄轨文物布局、相机 75°FOV 竖屏优化
- **展厅运行时配置**：服务端持久化渲染参数（scene-config.json），所有客户端共享；MUSEUM_ENABLE_GUI 开关控制调参面板
- **展厅 HTTPS 服务器**：局域网 IP 自动检测，WiFi/热点切换证书自动重签，二维码扫码访问
- **Windows 分发包**：一键打包脚本，嵌入 Node 运行时与 mkcert，离线可签证书

## 技术栈

- Next.js + TypeScript + Three.js + lil-gui
- 服务端运行时配置（runtime.env / scene-config.json）
- 完全自签 HTTPS（mkcert），支持纯局域网部署
