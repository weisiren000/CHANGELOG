# Interactive Cultural Relic Device v0.0.27（2026-05-18）

## 新功能
- 展厅运行时配置系统：服务端持久化渲染参数（scene-config.json），所有客户端共享同一份；MUSEUM_ENABLE_GUI 开关控制生产环境是否开放调参面板
- 展厅 HTTPS 服务器支持局域网 IP 自动检测，手机热点 / WiFi 切换时证书自动重签
- 待机屏保色彩模式：聚光小球在文物轨道上漫游，支持反色蒙版开关和圆外文物滤镜参数
- 待机模式支持摄像头取色匹配文物（颜色识别覆盖层）
- 待机屏保支持文物随机亮起效果，高亮轮播
- 年代轮播支持文物间隔与环形半径动态配置

## 改进
- 全量竖屏/窄屏适配：InfoPanel 滚动优化、窄轨文物布局、相机竖屏 75°FOV
- 颜色轴明度从 z 偏移改为径向偏移，移除 3D 颜色梯度表
- 颜色轴按色相排序，时间线添加颜色梯度图例
- 文物材质切换为 MeshBasicMaterial，移除 emissive 光照系统
- 轮播卡中心缩放效果优化，年代时间线增加吸附停靠
- 载入完成后默认切换到年代模式
- 面板按钮移至底部，底部控制栏隐藏逻辑全局化
- 待机屏保字体切换为华康金文，副标题增加篆书字体
- 配置保存/重置统一到场景层，移除时间线 GUI 重复按钮
- 移除以年代轴螺旋轨道配置及相关代码

## 问题修复
- 导出/导入配置时现在包含颜色层网格（TimelineConfig）
