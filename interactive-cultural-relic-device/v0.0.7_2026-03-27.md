# interactive-cultural-relic-device v0.0.7（2026-03-27）

## 新功能
- 增强文物聚焦视觉效果，支持背景场景的高饱和度去色与变暗处理
- `lil-gui` 面板集成文物展示预设系统 (Artifact Presets)，支持一键切换展示状态
- 全新的 3D 包围盒 (Bounding Box) 细粒度控制，支持各层面的透明度梯度调节

## 改进
- 优化聚焦模式切换逻辑，统一通过 UI 关闭按钮返回主视图
- 提升 3D 渲染性能与视觉层次感，打造博物馆级的全息展示视觉
- 强化 GUI 控制面板的布局与交互体验

## 问题修复
- 修复点击文物时背景迷雾效果不理想的问题
- 解决包围盒配置持久化同步的潜在边界问题
