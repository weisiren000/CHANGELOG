# 在聊天中预览代码，更方便地整理作品

聊天生成的 HTML 和 SVG 代码现在可以直接查看效果。项目库增加图片筛选和大图浏览，积分与订单信息也更容易查阅。

## 新功能

- 在聊天中打开 HTML 或 SVG 代码预览，支持切换源码、重新运行、全屏查看和下载文件。
- 图片项目库支持按文生图、图生图筛选，并可打开大图连续浏览作品。

## 体验改进

- 调整项目库的缩略图布局、作品信息和选择操作，方便浏览与整理作品。
- 积分明细增加额度批次展示，可查看剩余额度和到期时间。
- 订单记录更清楚地展示付款状态、优惠金额和购买时间。
- 优化账户菜单、消息中心和充值弹窗的交互与展示。
