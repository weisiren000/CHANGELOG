# dsh-remote-ops v0.0.8（2026-08-17）

## 新功能
- SSH 直连支持通过键盘交互方式完成登录密码认证
- 无法使用专用密钥保持连接的网关主机，断线后可在主机面板重新输入密码恢复会话

## 改进
- SSH 认证能够区分普通密码与验证码、多因素认证等交互提示，并对无法自动处理的认证给出明确说明
- 确保包含多个 `#` 的 SSH 用户名在连接过程中保持完整
- README 新增远程工作台界面预览

## 问题修复
- 修复部分 JumpServer 或堡垒机在用户名和密码正确时仍提示 SSH 身份认证失败的问题
- 修复启用 Full access 后远程工具仍可能被插件强制要求审批或直接拒绝的问题
- 修复专用密钥无法通过网关认证时连接被直接中断的问题
