# dsh-remote-ops v0.0.1（2026-08-15）

## 新功能
- 支持 SSH 直连远程主机，并保留 remote-hostd 高级配对方式
- 支持主机重连、连接诊断、健康状态和 SSH 指纹变更确认
- 支持远程任务取消、任务状态筛选和任务日志尾部查看

## 改进
- 主机面板显示连接状态、延迟、工作目录、最近错误和任务统计
- 远程任务日志持续写入，断线、超时、取消和中断状态分别展示
- 离线主机不会阻塞主机列表刷新
- 远程命令不再覆盖 DSH 的用户权限配置

## 问题修复
- 修复后台任务 ID 与远程任务日志 ID 不一致导致的查询失败
- 修复远程命令审批链路异常导致的工具报错
- 修复旧版主机和任务数据加载失败问题
