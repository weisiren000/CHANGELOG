# dsh-remote-ops v0.0.2（2026-08-16）

## 新功能
- 会话标题栏新增服务器入口和远程开发工作台
- 支持浏览、读取、编辑和保存远程文本文件
- 支持远程终端和插件、AI 文件变更审阅
- 支持主机健康诊断、手动重连和任务取消

## 改进
- SSH 连接断开后自动退避重连，并持续记录心跳、延迟和最近错误
- 文件保存增加版本冲突保护，避免覆盖远端新内容
- 任务日志支持尾部查询，运行中任务持续刷新
- 继续保留 SSH 直连默认入口和 remote-hostd 高级配对入口

## 问题修复
- 修复旧版主机和任务数据加载时缺少运维字段的问题
- 修复错误码、指纹变化和不可取消状态无法准确传递到前端的问题
