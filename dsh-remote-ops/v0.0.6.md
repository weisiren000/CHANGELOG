# dsh-remote-ops v0.0.6（2026-08-16）

## 新功能
- 支持通过 GitHub TAG 一条命令安装插件，无需手动克隆、构建或修改 Web 配置
- 远程任务日志支持有界尾部读取和大型内容分页查看
- 远程写入和审阅结果支持在历史会话中准确回放

## 改进
- 不同会话的默认远程主机彼此隔离，避免操作目标相互影响
- 取消、超时、主机移除和插件关闭具有更准确的任务终态
- 提升大型命令输出、远程日志和文件内容的稳定性
- 提升远程文件分页浏览、并发写入和变更审阅体验
- 重启后可恢复任务标识、任务归属和未完成任务状态
- 插件关闭时会等待远程连接、任务和后台刷新完全停止

## 问题修复
- 修复取消操作后远程命令仍可能继续运行的问题
- 修复远程文件路径可能越出指定工作区的问题
- 修复并发写入可能覆盖其他变更的问题
- 修复未获明确授权时远程操作可能继续执行的问题
- 修复旧版主机凭据迁移失败时可能留下公开明文的问题
- 修复大型输出或请求可能持续占用内存的问题
