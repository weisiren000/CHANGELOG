# Sutai-AI v0.0.43（2026-03-21）

## 新功能

- 引入消息列表虚拟滚动，长对话渲染更流畅
- 新增 OpenRouter 推理参数配置（effort / max_tokens / exclude）
- 对话列表和详情接口支持 Redis 缓存，降低数据库压力

## 改进

- 用户消息内容执行 HTML 清洗，防止 XSS 攻击
- 流式请求支持 Retry-After header，重试等待更精准
- 改进数据库唯一冲突错误处理，提示更准确

## 问题修复

- 修复分页 cursor 解码缺少 UTC 时区导致排序异常的问题
- 修复 cursor 和 offset 参数可同时传入的校验漏洞
- 修复数据库错误处理依赖字符串匹配的脆弱问题
