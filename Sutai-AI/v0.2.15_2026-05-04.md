# Sutai-AI v0.2.15（2026-05-04）

## 新功能
- 迁移至 DeepSeek V4 模型，默认切换为 deepseek-v4-flash，支持新的深度思考强度配置
- 新增 XML 工具调用流式解析，支持模型以 XML 标签格式触发工具调用
- 后端启动脚本统一为跨平台 Node.js 实现，移除旧版 PowerShell 启动脚本

## 改进
- 思考机制适配 DeepSeek V4 API 格式，支持 reasoning_effort 参数
- request_messages 贯穿整个聊天管线，优化消息上下文传递
- 热重载目录精确配置为 app 目录，减少无关文件触发重启
- 日志上下文重置增加异常防护，避免并发场景下崩溃
